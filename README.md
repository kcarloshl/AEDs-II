# AEDs II — Algoritmos e Estruturas de Dados

Repositório destinado ao armazenamento de exercícios, atividades práticas e materiais desenvolvidos durante a disciplina de **Algoritmos e Estruturas de Dados II (AEDs II)**, no curso de Sistemas de Informação.

## 📚 Conteúdo

- **Listas encadeadas:** implementação e manipulação de elementos utilizando ponteiros.
- **Filas:** operações de inserção e remoção de elementos.
- **Pilhas:** operações de empilhamento e desempilhamento.
- **Ponteiros em C:** utilização de endereços de memória na implementação de estruturas de dados.
- Exercícios e atividades práticas desenvolvidos durante as aulas.

## 🛠️ Tecnologias utilizadas

- Linguagem C
- Ponteiros e alocação dinâmica de memória
- Visual Studio Code
- Git e GitHub

## 🎯 Objetivo

Praticar a implementação e a manipulação de estruturas de dados utilizando a linguagem C, aprofundando os conhecimentos em ponteiros, organização da memória e lógica de programação.
